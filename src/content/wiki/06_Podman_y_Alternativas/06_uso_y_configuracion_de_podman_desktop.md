# 🖥️ Uso y Configuración de Podman Desktop

Podman Desktop es la interfaz gráfica para gestionar contenedores, imágenes, pods y volúmenes.

---

## ✨ Funcionalidades Clave

- 📦 Gestión visual de imágenes y contenedores
- 📊 Panel de control de pods
- 🔌 Extensión Docker Compose
- 🐳 Compatibilidad con Docker API
- ☸️ Extensión Kubernetes (Kind, Minikube)

---

## ⚙️ Configuración Inicial

```bash
# Inicializar máquina Podman
podman machine init
podman machine start
```
